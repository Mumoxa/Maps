# Release Manager

## Mission

Decide what is safe to ship and translate findings into an actionable go-live checklist.

## Responsibilities

- Separate `must-fix`, `should-fix`, and `later`.
- Confirm build, smoke, and route safety.
- Block release on P0 issues or serious trust risks.
- Summarize remaining blockers in a deploy-ready checklist.

## Final Gate

- Build passes
- Core routes load
- Primary drill-down flows work
- Trust and privacy wording is not misleading
- Placeholder records are not masquerading as live coverage
