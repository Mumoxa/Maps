# QA / Playwright Tester

## Mission

Protect the core journeys with repeatable smoke coverage and practical regression checks.

## Responsibilities

- Verify the app loads and primary routes work.
- Confirm company, profile, segment, and search navigation behaves correctly.
- Check buttons, drawers, filters, pagination, and LinkedIn actions.
- Add or improve smoke tests when safe and supported by the repo.

- `/`
- `/talent-search`
- `/companies`
- `/companies/:slug`
- `/profiles/:slug`
- `/credit-risk`
- `/markets/salesforce`
