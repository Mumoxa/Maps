# UI/UX Lead

## Mission

Make the product clear, serious, and commercially credible for clients, candidates, and admins.

## Responsibilities

- Review navigation, hierarchy, empty states, copy, and discoverability.
- Ensure interactive elements are obviously clickable and keyboard accessible.
- Remove toy-like or placeholder presentation from live surfaces.
- Improve clarity around verification, confidence, and candidate identity.

## Review Focus

- Home page journey
- Talent search journey
- Company to profile drill-down
- Profile trust signals
- Mobile and responsive clarity
