# Go-Live Audit

Use this skill when preparing SA Talent Map for client or candidate release.

## Audit Checklist

- Home page loads and positions the platform correctly.
- Company pages open and show their mapped profiles.
- Profile pages show LinkedIn/source links when URLs exist.
- Search and filters return expected results.
- Verification-pending records are clearly labeled.
- No placeholder content is presented as live coverage.
- Build passes.
- Deployment blockers are called out explicitly.

## Severity

- `P0`: app load failure, broken route, broken core drill-down, serious trust/privacy issue
- `P1`: misleading user journey, incomplete core flow, missing visibility of key evidence/actions
- `P2`: UX polish, empty states, clarity, copy, hierarchy
- `P3`: future improvements
