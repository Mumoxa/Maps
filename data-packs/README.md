# Data packs

This folder is the landing zone for repeatable market-map data packs. Each speciality map must eventually contain the same files:

- `profiles.json`
- `companies.json`
- `segments.json`
- `org_chart.json`
- `priority_shortlist.json`
- `summary.json`

The current credit-risk data still loads from the existing top-level JSON files. The folders here reserve the target structure for controlled migration and future XLS/XLSX imports.
